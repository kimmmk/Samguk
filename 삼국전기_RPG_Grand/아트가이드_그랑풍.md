# 삼국전기 RPG — 그랑풍 아트 가이드 (아트 바이블 v0.1)

모바일 수집형 삼국지 RPG(그랑삼국 등)의 **화풍 방향**을 참고해, 이 게임의 전체 그래픽을 고해상도 채색 2D로 다시 만드는 기준입니다.
참고 게임의 그림 · 캐릭터 디자인을 베끼거나 AI 학습 · 기준 그림으로 쓰지 않습니다. 모든 그림은 새로 만듭니다.

---

## 1. 그래픽 4층 구조

| 층 | 쓰임 | 형태 |
|---|---|---|
| ① 전투 SD | 전투 · 로비 · 군영 | **약 3등신 SD**, 부품 조립식 뼈대 애니메이션 (프레임 그림 아님) |
| ② 일러스트 | 등장 연출 · 필살기 컷인 · 협공 컷인 · 무장 선택 · 뽑기 | **6~7등신 전신 원화**, 화려한 포즈 · 이펙트 |
| ③ 배경 | 스테이지 · 로비 | 채색 일러스트 배경, 원경 · 중경 · 지면 3단 시차 스크롤 |
| ④ 연출 · UI | 보스 등장, 기술 효과, 화면 틀 | 빛 번짐(가산 합성) 이펙트, 금장 테두리 UI |

## 2. 전투 SD 캐릭터

### 비율 · 시점
- **3등신**: 머리 1 : 몸통 1 : 다리 1. 머리(투구 포함)가 키의 약 1/3.
- 시점: **오른쪽을 보는 3/4 측면** (왼쪽은 좌우 반전). 얼굴은 약간 관객 쪽으로 돌림.
- 손은 크고 단순하게(주먹), 발은 작고 각지게. 무기는 몸보다 크게(창 · 언월도는 키의 1.3~1.6배).

### 선 · 채색
- **외곽선**: 실루엣 바깥선이 가장 굵고(원화 기준 5~7px), 안쪽 선은 그 절반. 순검정 대신 짙은 고동 · 남색.
- **채색**: 셀 2단(기본 + 그림자) + 하이라이트 1단. 금속은 강한 반사띠 2줄, 금장은 노랑 → 주황 → 갈색 3단.
- **광원**: 왼쪽 위 고정. 몸 오른쪽(관객 반대쪽)에 약한 림라이트.
- **채도**: 높게. 세력색은 갑옷 · 망토 · 장식 천에 크게 쓴다.

### 세력 · 무장 색 (대표색)
| 구분 | 주색 | 보조 |
|---|---|---|
| 촉 | 녹 · 흰 | 금 |
| 위 | 남 · 청 | 은 |
| 오 | 적 · 주황 | 금 |
| 군웅(동탁 · 원소 · 황건) | 흑적 / 황토 / 황 | 각 세력 금속색 |
| 조운 | 은 · 흰 갑주, 청 망토 | 붉은 깃 · 금 테 |

### 부품 구성 (렌더러 규격 — `js/sdart.js` 의 관절과 같다)
그리는 순서(뒤 → 앞): 망토 → 뒷머리 → 뒷팔 → 뒷다리 → 앞다리 → 허리갑 · 치마 → 몸통 → 앞 견갑 → **머리** → 무기 → 앞팔

| 부품 | 관절(회전 중심) | 비고 |
|---|---|---|
| 머리(투구 · 얼굴 · 앞머리) | 목 | 표정 교체를 위해 얼굴은 나중에 분리 가능 |
| 몸통(가슴 · 허리띠) | 목 | 팔에 가려진 부분까지 채워 그린다 |
| 허리갑 · 치마 | 엉덩이 | |
| 앞팔 / 뒷팔 | 어깨 | 한 장(위팔 + 아래팔 + 주먹). 뒷팔은 앞팔을 어둡게 해서 재사용 가능 |
| 앞다리 / 뒷다리 | 엉덩이 관절 | 한 장(허벅지 + 정강이 + 신발). 윗부분은 치마 속으로 들어가게 길게 |
| 망토 | 등 어깨 | 바람에 흔들림(회전) |
| 무기 | 손 | 무기별 한 장, 쥐는 위치 · 날끝 좌표 기록 |

- 관절 끝은 **둥글게 겹치게**(관절 주변 15~20% 여유) 그려 회전해도 틈이 안 생기게 한다.
- 원화 기준: 캐릭터 키 약 **900px**(캔버스 832×1216). 게임에서는 키 약 170 논리px(화면 340px)로 줄여 그리므로 충분히 선명하다.

## 3. 일러스트 (컷인 · 선택 화면)
- 6~7등신, 1024×1536 이상. 무장마다 전신 1장 + 컷인용 상반신 1장.
- 역동적 포즈(무기를 크게 휘두르거나 겨눔), 배경은 투명 또는 이펙트 배경.
- 같은 무장의 SD와 의상 · 색 · 무기가 일치해야 한다(무장 LoRA 공유).

## 4. 배경
- 스테이지마다 3단: **원경**(하늘 · 산 · 성곽 실루엣, 느리게) · **중경**(건물 · 나무) · **지면**(길 · 돌바닥, 캐릭터가 서는 면).
- 논리 해상도 960×540 기준, 원화는 2배(1920×1080) 이상. 가로로 이어 붙일 수 있게 좌우 이음매 처리.
- 캐릭터보다 채도 · 대비를 한 단계 낮춰 캐릭터가 떠 보이게 한다.

## 5. 보스 · 연출
- 일반 보스: SD 무장의 1.3~1.5배. **각성 · 악마형 보스**: 화면 높이의 절반 이상, 별도 대형 원화 + 오라 이펙트.
- 이펙트: 가산 합성 빛(검기 · 오라 · 번개), 기술마다 대표색 1개. 필살기 컷인은 일러스트 + 굵은 붓글씨 기술명.

## 6. UI
- 금장 테두리(금 3단 + 짙은 남색 안쪽), 둥근 초상화 틀, 붓글씨풍 제목 글자.
- HUD는 화면 위 좌우, 기술 버튼은 아래 — 전투 화면을 가리지 않게.

## 7. 제작 순서
1. **수직 슬라이스**: 조운 SD 부품 → 병사 1종 → 보스 1명 → 배경 1장 → 전투 UI 까지 한 스테이지 완성형.
2. 공정 확정 후 무장 12 · 병사 7종 × 세력 색 · 보스 11 · 배경 10 으로 확장.
3. 일러스트 · 컷인 · 대형 보스 연출 · UI.

## 8. 저작권
- 참고 게임은 **방향 참고만**. 화면 캡처 · 원화를 학습 데이터 · IP-Adapter 기준 그림 · 트레이싱에 쓰지 않는다.
- AI 생성 기준 그림은 우리 프롬프트 · 우리 LoRA(조운 · 관우)로 만든 것만 쓴다.
