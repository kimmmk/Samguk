# 삼국전기 RPG 3D (팬메이드 오마주)

「삼국전기_RPG」(2D 캔버스판)의 시나리오 · 무장 · 스테이지 · RPG 구성을 그대로 따르고,
그래픽을 실시간 3D 셀 셰이딩(원신풍)으로 새로 만든 버전입니다.

원작: 三國戰紀 (Knights of Valour) © IGS. 원작의 이미지나 음원은 쓰지 않았고, 모든 그래픽 · 효과음 · 음악은 코드로 생성합니다.

## 실행

- `index.html`을 브라우저(Chrome · Edge 최신)로 엽니다.
- three.js와 글꼴을 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- `js` 폴더는 `index.html` 옆에 있어야 합니다.
- 남성 한국어 음성(TTS)은 Edge에서 가장 자연스럽습니다. 음성은 `B` 키로 켜고 끕니다.

## 조작

| 동작 | 키 |
|---|---|
| 이동 | 방향키 / WASD |
| 공격 (3단 콤보) | Z · J · F |
| 점프 | X · K · G · Space |
| 필살기 (↑+필살 / 5 = 신화 무기 필살기) | C · L · H |
| 회피 | 왼쪽 Shift · O |
| 아이템 사용 / 전환 | V · U · R / E · Q · I |
| 단축 스킬 | 1 · 2 · 3 · 4 |
| 캐릭터 창 | Tab · T |
| 일시정지 | P · Esc |
| 배경음 / 음성 | N / B |

커맨드: ↓→+공격 전용기 · ↓↑+공격 승천격 · →→ 달리기(+공격 돌진) · 공격+점프 무적 회전베기.

무장별 신규 커맨드 5종 (방향은 캐릭터가 바라보는 쪽 기준, 오른쪽을 볼 때):

| 입력 | 기력 | 예 (관우) |
|---|---|---|
| ↓ ← + 공격 | 15 | 청룡반월 |
| ← → + 공격 | 15 | 천리주단기 |
| ↓ ↓ + 공격 | 20 | 언월진산 |
| ↑ ↓ + 공격 | 20 | 청룡강림 |
| → ↓ → + 공격 | 25 | 승룡참 |

무장마다 기술 이름 · 동작 · 속성 연출이 다릅니다.

연속기 · 회피 기술:

| 입력 | 동작 |
|---|---|
| 공격 길게 누르기 | 모아베기 (풀 차지 시 강화) |
| 공중에서 공격 ×3 / 공중 ↓ + 공격 | 공중 3연격 / 급강하 내려찍기 |
| 공격 중 점프 | 점프 캔슬 (승천격 뒤에는 추격 점프) |
| 회피 중 공격 | 회피 반격 (완벽 회피 뒤 강화) |
| 회피 중 회피 / 공중에서 회피 | 연속 회피 (기력 8) / 공중 대시 |
| 다운 · 경직 중 회피 | 낙법 (기력 15) |
| 10 · 30 · 50 · 100 · 200 콤보 | 콤보 보너스 (공격력 최대 +25%, 기력 회복) |

전장 대화 중에 공격 · 이동 · 점프 · 회피 등을 입력하면 대화가 바로 넘어갑니다. 일시정지 메뉴와 도움말에 현재 무장의 커맨드가 표시됩니다.

## 구성

- **시나리오 · 데이터**: 원본의 `data.js`(무장 · 적 · 스테이지 · 보스 국면)와 `rpgdata.js`(등급 · 장비 · 세트 · 전용/신화 · 스킬 트리)를 **수정 없이** 불러옵니다. `stagedata.js`는 원본 `stageev.js`의 대사 · 이벤트 · 군영 대화 · 화용도 선택 데이터 부분입니다.
- **스토리**: 탁현 → 호뢰관 → 백마 → 박망파 → 장판파 → 적벽 → 화용도 → 정군산 → 번성 → 비장 오장원, 무장별 분기 대사, 화용도 의/패 선택, 천하삼분 · 한실부흥 결말, 숨겨진 보물 4종, 히든 무장 여포.
- **전장 목표**: 성문 돌파, 미부인 호위, 화공(황개 원군), 추격 시간, 화살비, 수공, 칠성등 방어.
- **무장별 동작**: 무장마다 고유 연속기(3~5타, 자세 14종), 테마 색 · 입자(청룡 · 대지 · 빙설 · 화염 · 뇌전 · 꽃잎 · 금빛 · 진홍), 스킬 시전 연출.
- **필살기 연출**: 레터박스 · 화면 암전 · 카메라 줌 · 광선 · 거대 무장 환영 · 대형 마법진 · 3D 초상 컷인, 본 공격 약 2배 지속, 한자 일섬 피니시.
- **타격/피격 이펙트**: 섬광 · 베기 흔적 · 방향성 불꽃 · 적 찌그러짐 · 치명타 표시, 피격 시 붉은 화면 · 저체력 심장박동.
- **장비 추천**: 가방에 현재 장비보다 기본 옵션(공격/방어)이 같거나 높고 전투력이 오르는 장비가 있으면 캐릭터 창 「장비 추천」이 켜집니다. 추천 부위가 강조되고, 부위를 누르면 추천 장비가 전투력 증가 순으로 표시됩니다. 전장에서 추천 장비를 주우면 알림이 뜹니다.
- **세트 아이템**: 15종 모두 4부위 이상. 부위 하나는 에픽 수준(에픽 기본치 + 세트 고유 옵션 + 에픽 무작위 옵션 2~3개, 대장간 재련 시 고유 옵션 유지)이고, 착용 수에 따라 효과가 쌓입니다.
  - 2세트: 시너지 효과 + 옵션 2개 (세트 등급 수치)
  - 3세트: + 옵션 3개 (전용 등급 수치)
  - 4세트: + 옵션 4개 (신화 등급 수치) + 시너지 각성
  - 옵션 수치는 착용한 세트 부위의 평균 아이템 레벨로 계산됩니다. 5~6부위 세트는 원하는 4부위를 골라 4세트를 맞출 수 있습니다.
- **무기 강화 외형**: 강화 단계에 따라 무기 모양이 바뀌고 전투 · 군영 · 캐릭터 창 미리보기에 모두 적용됩니다. +3 연마(밝은 날) · +5 광휘(발광) · +7 금장(금빛 광채 · 장식 수술 · 휘두를 때 금빛 잔광) · +10 염화(무기 확대 · 불꽃 외피 · 타격 시 화염 파편) · +12 보주(무기 주위를 도는 구슬 3개) · +13 뇌광(자색 외피 · 타격 시 번개) · +15 신병(무지개 외피 · 후광 · 치명타 시 오색 섬광). 대장간에서 현재 단계와 다음 단계를 보여 줍니다.
- **전투**: 병종 역할(방패병 · 기병 · 기수 · 사기 붕괴), 정예 몬스터, 보스 국면 · 경직 게이지 · 분노 필살기, 원소 반응, 완벽 회피.
- **RPG**: 레벨 · 능력치 · 3계열×5단계 스킬 트리, 6등급 장비, 군영(대장간 · 상인 · 도박장 · 저장 슬롯 · 윤회).
- **외형**: 기본은 **마인크래프트 블록 스타일**(블록 캐릭터 · 픽셀 스킨 · 투구/갑옷 레이어 · 픽셀 무기 · 블록 군마 · 블록 전장 · 픽셀 아이콘). 타이틀 메뉴 「외형」에서 사실적 셀 셰이딩으로 바꿀 수 있습니다.
- **그래픽(사실적 모드)**: 6~7등신 캐릭터, 페인팅 얼굴 텍스처, 찰갑 · 견갑 · 요갑, 부위별 장비 외형, 캐릭터 창 3D 미리보기(부위 강조), 강화 단계 이펙트, 아이템 · 스킬 일러스트 아이콘.
- **음성**: Web Speech API로 인물의 나이 · 성격에 맞춘 목소리(대사 · 해설 · 기술 외침).

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구성 · 스타일 |
| `js/data.js`, `js/rpgdata.js` | 원본 데이터 (수정 없음) |
| `js/stagedata.js` | 원본 전장 대화 · 이벤트 데이터 |
| `js/engine.js` | 렌더러 · 셰이더 · 파티클 · 이펙트 · 효과음 · 무기/군마 모델 · 포즈 |
| `js/chars.js` | 사실적 캐릭터 모델(얼굴 · 갑옷 텍스처) · 장비 외형 |
| `js/mc.js` | 마인크래프트 스타일 캐릭터 · 무기 · 군마 · 블록 전장 |
| `js/icons.js`, `js/skillicons.js` | 아이템 · 스킬 일러스트 아이콘 |
| `js/env.js` | 전장 배경 · 군영 |
| `js/rpg.js` | 능력치 · 장비 생성 · 드랍 · 대장간 · 저장 |
| `js/voice.js` | 인물별 음성(TTS) |
| `js/moves.js` | 무장별 연속기 · 신규 커맨드 · 필살기 연출 · 타격/피격 이펙트 |
| `js/combat2.js` | 대화 스킵 · 회피 기술 · 공중/차지/캔슬 연속기 · 콤보 보너스 |
| `js/sets.js` | 세트 아이템 구성 · 2/3/4세트 효과 · 세트 툴팁 |
| `js/wenh.js` | 무기 강화 단계별 외형 · 전투 잔광/타격 효과 |
| `js/game.js` | 전투 · 적 AI · 보스 · 전장 이벤트 · 스킬 · 장면 흐름 |
| `js/ui.js` | HUD · 대화 · 메뉴 · 군영 · 캐릭터 창 · 상인 · 도박장 |

저장 데이터는 브라우저 저장소(localStorage)에 보관되며 원본 2D판 세이브와는 호환되지 않습니다.
