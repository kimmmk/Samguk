# 삼국전기 RPG 3D (팬메이드 오마주)

「삼국전기_RPG」(2D 캔버스판)의 시나리오 · 무장 · 스테이지 · RPG 구성을 그대로 따르고,
그래픽을 실시간 3D 셀 셰이딩(원신풍)으로 새로 만든 버전입니다.

원작: 三國戰紀 (Knights of Valour) © IGS. 원작의 이미지나 음원은 쓰지 않았고, 모든 그래픽 · 효과음 · 음악은 코드로 생성합니다.

## 실행

- `index.html`을 브라우저(Chrome · Edge 최신)로 엽니다.
- three.js와 글꼴을 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- `js` 폴더는 `index.html` 옆에 있어야 합니다.
- 남성 한국어 음성(TTS)은 Edge에서 가장 자연스럽습니다. 음성은 `B` 키로 켜고 끕니다.

## 조작

| 동작 | 키 |
|---|---|
| 이동 | 방향키 / WASD |
| 공격 (3단 콤보) | Z · J · F |
| 점프 | X · K · G · Space |
| 필살기 (↑+필살 / 5 = 신화 무기 필살기) | C · L · H |
| 회피 | 왼쪽 Shift · O |
| 아이템 사용 / 전환 | V · U · R / E · Q · I |
| 단축 스킬 | 1 · 2 · 3 · 4 |
| 캐릭터 창 | Tab · T |
| 일시정지 | P · Esc |
| 배경음 / 음성 | N / B |

커맨드: ↓→+공격 전용기 · ↓↑+공격 승천격 · →→ 달리기(+공격 돌진) · 공격+점프 무적 회전베기.

## 구성

- **시나리오 · 데이터**: 원본의 `data.js`(무장 · 적 · 스테이지 · 보스 국면)와 `rpgdata.js`(등급 · 장비 · 세트 · 전용/신화 · 스킬 트리)를 **수정 없이** 불러옵니다. `stagedata.js`는 원본 `stageev.js`의 대사 · 이벤트 · 군영 대화 · 화용도 선택 데이터 부분입니다.
- **스토리**: 탁현 → 호뢰관 → 백마 → 박망파 → 장판파 → 적벽 → 화용도 → 정군산 → 번성 → 비장 오장원, 무장별 분기 대사, 화용도 의/패 선택, 천하삼분 · 한실부흥 결말, 숨겨진 보물 4종, 히든 무장 여포.
- **전장 목표**: 성문 돌파, 미부인 호위, 화공(황개 원군), 추격 시간, 화살비, 수공, 칠성등 방어.
- **전투**: 병종 역할(방패병 · 기병 · 기수 · 사기 붕괴), 정예 몬스터, 보스 국면 · 경직 게이지 · 분노 필살기, 원소 반응, 완벽 회피.
- **RPG**: 레벨 · 능력치 · 3계열×5단계 스킬 트리, 6등급 장비, 군영(대장간 · 상인 · 도박장 · 저장 슬롯 · 윤회).
- **외형**: 기본은 **마인크래프트 블록 스타일**(블록 캐릭터 · 픽셀 스킨 · 투구/갑옷 레이어 · 픽셀 무기 · 블록 군마 · 블록 전장 · 픽셀 아이콘). 타이틀 메뉴 「외형」에서 사실적 셀 셰이딩으로 바꿀 수 있습니다.
- **그래픽(사실적 모드)**: 6~7등신 캐릭터, 페인팅 얼굴 텍스처, 찰갑 · 견갑 · 요갑, 부위별 장비 외형, 캐릭터 창 3D 미리보기(부위 강조), 강화 단계 이펙트, 아이템 · 스킬 일러스트 아이콘.
- **음성**: Web Speech API로 인물의 나이 · 성격에 맞춘 목소리(대사 · 해설 · 기술 외침).

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구성 · 스타일 |
| `js/data.js`, `js/rpgdata.js` | 원본 데이터 (수정 없음) |
| `js/stagedata.js` | 원본 전장 대화 · 이벤트 데이터 |
| `js/engine.js` | 렌더러 · 셰이더 · 파티클 · 이펙트 · 효과음 · 무기/군마 모델 · 포즈 |
| `js/chars.js` | 사실적 캐릭터 모델(얼굴 · 갑옷 텍스처) · 장비 외형 |
| `js/mc.js` | 마인크래프트 스타일 캐릭터 · 무기 · 군마 · 블록 전장 |
| `js/icons.js`, `js/skillicons.js` | 아이템 · 스킬 일러스트 아이콘 |
| `js/env.js` | 전장 배경 · 군영 |
| `js/rpg.js` | 능력치 · 장비 생성 · 드랍 · 대장간 · 저장 |
| `js/voice.js` | 인물별 음성(TTS) |
| `js/game.js` | 전투 · 적 AI · 보스 · 전장 이벤트 · 스킬 · 장면 흐름 |
| `js/ui.js` | HUD · 대화 · 메뉴 · 군영 · 캐릭터 창 · 상인 · 도박장 |

저장 데이터는 브라우저 저장소(localStorage)에 보관되며 원본 2D판 세이브와는 호환되지 않습니다.
