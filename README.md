# 삼국전기 RPG (팬메이드 오마주)

브라우저에서 바로 실행되는 삼국지 벨트스크롤 액션 RPG입니다. 같은 게임을 네 가지 그래픽으로 담았습니다.

| 폴더 | 내용 |
|---|---|
| `삼국전기_RPG` | 원본 — 그랑삼국풍 SD 캐릭터(코드로 그린 벡터 그림) |
| `삼국전기_RPG_HD2D` | HD-2D 에디션 — 피사계 심도 · 블룸 · 빛줄기 후처리 |
| `삼국전기_RPG_DNF` | 도트 에디션 — 던전앤파이터풍 도트, 스프라이트 시트 렌더러 · 베이커 |
| `삼국전기_RPG_3D` | 3D 에디션 — three.js 실시간 3D (마인크래프트풍 블록 / 사실적 셀 셰이딩 전환), 무장별 연속기 · 커맨드, 강화 단계별 장비 외형, 적 등급별 외형. 자세한 내용은 폴더의 `README.md` |

## 실행

각 폴더의 `index.html`을 브라우저로 엽니다. 조작법과 공략은 각 폴더의 `사용법.txt`에 있습니다.

## 도트 에디션 스프라이트

- `sprites/` — 무장 12명 · 보스 11명 · 병사 28종 스프라이트 팩(격자 시트 + 실행용 아틀라스)
- `sprites/ai_*` — AI로 생성한 팩: 조운 · 관우(46프레임 — 1~3타 · 점프 · 회피 · 스킬 · 승리 등), 병사 6종 × 4세력, 보스 11명. `sprites/manifest.js`에서 `ai_…` 항목을 빼면 기존 팩으로 돌아갑니다.
- 밑그림 생성 · 아틀라스 갱신: `python tools/bake_server.py` 실행 후 `http://127.0.0.1:8777/tools/spritebaker.html`
- 도트 작가용 규격 · 작업 흐름: `스프라이트_제작가이드.md`
- AI 팩을 만든 스크립트: `sprite_ai/` (설치 · 실행 순서는 `sprite_ai/README.md`)
- `tools/gallery.html` — 캐릭터 전체를 크게 늘어놓고 보는 확인용 페이지
